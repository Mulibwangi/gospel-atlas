How to unzip

Windows — right-click the ZIP, choose Extract All, then Extract. Open the new folder that appears.

macOS — double-click the ZIP. A folder of the same name appears beside it.

Linux — right-click the ZIP and choose Extract Here, or run unzip in a terminal.

What is in the folder

Gospel_Atlas_David_Lee.html — the app itself. This one file holds the maps, the Scripture editions and the cross-references.

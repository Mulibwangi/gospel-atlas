Shadow and Substance

Places where Scripture reads itself: a verse states that one passage answers another, and the verse is given. Nothing here is inferred, and nothing is included because it is traditional. Every line opens to the text it rests on.

Scripture says so

    What this is

    Twelve correspondences, each asserted by a verse that is quoted in full. The readings tradition adds to these are not here.

    The passages

      Scripture is the American Standard Version of 1901, which is in the public domain. A mark of linked beside a pair means the OpenBible.info cross-reference dataset, CC BY, records a direct reference between those two chapters; no link means it does not. That is a fact about an editorial dataset and not a judgement about the correspondence.

      The short description beside each pair is a plain label for what the verse says happens, not a comment on it. Where the two columns join in crossing lines rather than parallel ones, the second passage answers the first in reverse order.
